# Квіз-лендінг «Клієнти через TikTok»

Односторінковий квіз для реклами: інтро → 3 питання → форма заявки. З підключеним Meta Pixel і подією **Lead** на відправку форми.

## 📁 Структура
```
tiktok-quiz/
├── index.html        ← весь квіз (дизайн + питання + піксель)
├── api/lead.js       ← приймає заявку та шле в Telegram (Vercel)
└── videos/           ← сюди 3 відео: video1.mp4, video2.mp4, video3.mp4
```

## ✅ Що зробити перед запуском (3 кроки)

### 1. Вставити свій Meta Pixel
Відкрий `index.html`, угорі знайди блок `META PIXEL` і заміни **`PIXEL_ID`** на свій номер пікселя (з Events Manager). Він зустрічається у **двох місцях** — заміни в обох.

Як отримати ID: [business.facebook.com](https://business.facebook.com) → **Events Manager** → твій піксель → номер угорі (16 цифр).

### 2. Додати 3 відео
Поклади відео в папку `videos/` з іменами `video1.mp4`, `video2.mp4`, `video3.mp4`. Підписи (імʼя, вік, результат) міняються в `index.html` у блоці `<div class="videos">`.

### 3. Налаштувати отримання заявок у Telegram
Інструкція — всередині файлу `api/lead.js`. Коротко: створити бота через @BotFather, додати у Vercel змінні `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID`.

## 🚀 Деплой на Vercel
```bash
npm i -g vercel      # один раз
cd tiktok-quiz
vercel               # перший раз — відповідай на питання
vercel --prod        # викласти на бойовий домен
```
Або через сайт: vercel.com → **Add New → Project** → перетягни папку / підключи Git.

## 🎯 Як перевірити, що подія Lead працює
1. Встанови розширення **Meta Pixel Helper** (Chrome).
2. Відкрий свій сайт → пройди квіз до кінця → відправ форму.
3. У значку Pixel Helper має зʼявитись **PageView** (одразу) і **Lead** (після відправки форми).
4. Додатково: Events Manager → твій піксель → вкладка **Test Events** → введи адресу сайту → пройди квіз → побачиш події в реальному часі.
